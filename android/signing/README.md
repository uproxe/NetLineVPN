# Ключ подписи Android

`netline.jks` — открытый ключ подписи (пароль `netline-public`, псевдоним `netline`).
Он лежит в репозитории специально: так любая сборка из GitHub Actions подписана одним ключом,
и новая версия ставится поверх старой без удаления.

Чтобы подписывать своим секретным ключом, добавьте в секреты репозитория
`ANDROID_KEYSTORE_BASE64`, `ANDROID_KEYSTORE_PASSWORD` и `ANDROID_KEY_ALIAS` — сборка возьмёт их.
Важно: после смены ключа приложение придётся один раз переустановить.
