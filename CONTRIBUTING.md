# Участие в разработке

- Интерфейс и вся логика разбора ссылок и сборки конфигураций — в `ui/` (обычный JavaScript без сборщиков),
  общий для компьютера и Android. Тесты: `node tests/test.js`.
- Проверка конфигураций настоящими ядрами (Linux, нужен интернет): `bash tests/check-configs.sh`.
- Программа для компьютера — `desktop/` (Tauri 2, Rust), для Android — `android/` (Java).
- Версия меняется в двух местах: `VERSION` и `desktop/Cargo.toml`, плюс раздел в `CHANGELOG.md`.
  После попадания в `main` релиз соберётся и опубликуется сам.
- Сообщения коммитов — по-русски, коротко: «android: плитка показывает подключение».
